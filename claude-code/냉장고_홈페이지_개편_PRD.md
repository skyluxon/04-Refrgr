## 1. 개요

기존에는 식품제조업체·빙과사·프랜차이즈 등 대형 기업 고객만을 대상으로 영업/납품해 온 냉장·냉동 쇼케이스 사업을, 다음 두 방향으로 판로를 확대한다.

1. **일반 냉장고**: 대형 식품제조업체 → **소매 상공인**(식당, 정육점, 카페 등 개인/소상공인 사업자)
2. **특수 냉장고**: 정부기관(조달) → **의료기관, 참치 전문 횟집 등** 전문 업종

※ 이하 본문에서 "일반 냉장고", "특수 냉장고"는 편의상의 표기이며, 실제로는 세광시앤에치의 상업용 냉장·냉동 쇼케이스 제품군을 지칭한다.

이번 개편의 1차 목표는 **여러 광고 매체를 통해 유입되는 신규 방문자가 제품과 회사에 대한 신뢰를 형성하고 상담/문의로 전환되는 홈페이지**를 만드는 것이다. 소비자 결제(전자상거래) 기능은 이번 범위에서 제외하고 후속 단계에서 구현한다.

## 2. 배경 및 문제 정의

### 현재 사이트 진단 (실제 화면 확인 결과)

세광시앤에치의 실제 홈페이지(sekwangcnh.com)를 확인한 결과는 다음과 같다.

**이미 갖춰진 자산**
- 얼음/냉동 컨셉의 다크블루 톤 브랜드 아이덴티티가 일관되게 적용되어 있음 ("SEKWANG, Leading the Future of Freezing Technology")
- 설치 사례 섹션("매장의 품격을 한층 업그레이드하다")이 이미 존재 — 실제 매장 설치 사진과 모델명 노출
- 전화, 인스타그램, 페이스북, A/S문의, 오시는길 등 연락 채널 다양
- 제품문의/카탈로그 CTA 존재
- **회사소개 페이지에 연혁(History)이 매우 상세**: 1991년 세광산업 설립 → 1992 국가지정 A/S업체·삼성물산 협력업체 → 2008 ISO 9001/14001 → 2016 Inno-Biz → 2021 Main-Biz → 2023 경기도 스타기업까지 타임라인으로 정리, 조직도(생산1~5팀, 국내/해외영업)도 공개 — 신뢰 자산이 이미 풍부함
- **설치사례가 페이지네이션 4페이지(약 40건+) 분량**으로 편의점·마트·베이커리·아이스크림 브랜드(하겐다즈, 딥핀도츠 등) 설치 사례가 다양하게 존재
- **"온라인 구매문의" 메뉴가 이미 존재** — 업종별 상담 폼으로 확장 가능한 기반
- 고객지원에 FAQ 섹션 존재 (단, 아래 "개편 필요 부분" 참고)

**개편이 필요한 부분**
- 상단 메뉴(제품소개/회사소개/홍보센터/고객지원)와 메인 "Featured Products"가 전부 **제품 유형 기준**(냉동/냉장/겸용/베이커리/아이스크림/주문형 쇼케이스)으로만 분류되어 있어, 확장하려는 **고객 업종 기준** 분류(식당·정육점 vs 의료기관·참치전문점)가 없음
- 설치사례가 업종별로 필터링되어 있지 않아, 방문자가 자신의 업종과 유사한 사례를 빠르게 찾기 어려움
- 기존 FAQ는 "쇼케이스 설치방법", "성에 제거", "소음" 등 **기술지원(A/S) 성격**만 있고, 구매를 고민하는 소상공인이 궁금해할 **구매결정 FAQ**(가격대, 설치 가능 지역, 소요 기간 등)는 없음
- 소상공인 대상 신뢰 요소(동종업계 사장님 후기)가 없음 — 설치사례는 있으나 "후기/평가" 형태는 아님
- 특수 쇼케이스(의료기관·참치전문점용) 관련 인증·스펙 자료 노출이 없음 — 다만 기존 ISO/Inno-Biz/Main-Biz 등 일반 신뢰 인증은 이미 있으므로 이를 재구성/강조하는 것으로 상당 부분 해결 가능
- 연락 이메일이 법인 도메인이 아닌 개인 네이버 이메일(cnh4204@naver.com) — 전문성 측면에서 개선 검토 필요 (우선순위 낮음)

**확인 완료 사항**
- 푸터에 노출되는 "Whaaa", "Cold&Hot"은 별도 사업부/제품군 브랜드가 아님. "Whaaa"는 회사 철학문에 등장하는 **고객 감동 슬로건**("감동찬사(Whaaa)를 받을 때까지..."), "Cold&Hot"은 냉장·냉동은 물론 온장(베이커리 쇼케이스 등)까지 아우르는 **회사 사업 전체를 관통하는 핵심 아이덴티티**. 신규 업종별 랜딩의 히어로 메시지에서도 이 정체성을 계승해 브랜드 일관성을 유지할 필요가 있음

### 문제 정의

- 현재 홈페이지는 **제품 카탈로그 중심 B2B 구조**로 잘 설계되어 있으나, 신규 타겟(소상공인, 특정 전문 업종)의 검토 기준을 반영한 콘텐츠/진입 경로가 없다.
- 신규 타겟은 기존 대형 고객과 **의사결정 기준이 다르다.**

| 구분 | 기존 대형 B2B 고객 | 신규 확대 대상 |
|---|---|---|
| 의사결정자 | 구매팀, 설비담당자 | 사업주 본인(비전문가인 경우多) |
| 검토 기준 | 스펙시트, 인증서, 납품실적 | 가격, A/S 신속성, 동종업계 사례, 후기 |
| 진입 경로 | 영업사원 컨택, 입찰 | 광고(검색/SNS) → 홈페이지에서 즉시 판단 |
| 특수 냉장고 검토 기준 | 조달 규격 충족 여부 | 위생·정밀온도 인증, 업종별 적합성 |

- 기존 홈페이지 구조로는 위 신규 타겟의 검토 기준(신뢰 요소, 사례, 후기)을 전달할 수 없어 광고 유입 트래픽이 전환되지 못하고 이탈할 위험이 크다.

## 3. 목표 및 성공 지표

### 목표
- 광고 매체 유입 방문자가 제품/회사에 대한 신뢰를 갖고 **상담·견적 문의**로 전환되는 홈페이지 구축
- 일반 냉장고(소매 상공인)와 특수 냉장고(의료기관·참치 전문점)의 니즈가 다르므로 **랜딩 경험을 분리**

### KPI (제안, 운영팀 확정 필요)
- 광고 유입 대비 상담문의 전환율(CVR)
- 채널별(네이버/메타/구글 등) 랜딩페이지 이탈률
- 문의 폼 완료율, 문의 후 실제 상담 성사율
- 페이지 로딩 속도(LCP 2.5초 이내), 모바일 트래픽 비중 대응

## 4. 대상 사용자 (User Segments)

| 세그먼트 | 특징 | 핵심 니즈 |
|---|---|---|
| A. 소매 상공인 (일반 냉장고) | 식당/정육점/카페 등 개인사업자, 비전문가, 빠른 의사결정 선호 | 가격, 설치 편의성, A/S, 동종업계 사례 |
| B. 의료기관 (특수 냉장고) | 시설관리/구매 담당자, 위생·정밀도 규정 준수 필요 | 인증서, 정밀 온도관리 스펙, 납품실적 |
| C. 참치 전문 횟집 등 (특수 냉장고) | 사업주 본인, 실무형 의사결정 | 신선도 유지 성능, 업계 평판, 실제 사용 사례 |
| D. 기존 대형 B2B 고객 (유지) | 구매팀/설비담당 | 기존 카탈로그·조달 정보 유지 필요 |

세그먼트 A는 B2C적 신뢰 형성이, B/C는 전문성 기반 신뢰 형성이 중요하여 **콘텐츠 톤과 구조를 분리**한다.

## 5. 범위 (Scope)

### In Scope (1차 개편)
- 신뢰 형성 중심의 홈페이지 콘텐츠/구조 개편
- 일반 냉장고(소매 상공인) 전용 랜딩 섹션/페이지
- 특수 냉장고(의료기관·참치 전문점) 전용 랜딩 섹션/페이지
- 회사 공통 정보(회사소개, 연혁, 인증, 오시는길) 유지 및 양쪽 랜딩에서 접근 가능하도록 연결
- 상담/문의 폼 (결제 아님, 리드 수집 목적)
- 광고 매체별 유입 추적을 위한 UTM/GA4 등 분석 도구 연동
- 반응형(모바일 우선) 대응

### Out of Scope (후속 단계)
- 온라인 결제/장바구니/주문관리 (Phase 2)
- 회원가입/마이페이지
- 재고 연동, 배송 추적

## 6. 정보구조 (Sitemap)

현재 실제 메뉴는 `제품소개 | 회사소개 | 홍보센터 | 고객지원` 이며, 제품소개 하위가 전부 제품 유형(냉동/냉장/겸용/베이커리/아이스크림쇼케이스/주문형) 기준이다. 아래와 같이 업종 기준 진입 경로를 추가한다.

```
메인 도메인
├─ 공통 헤더/푸터 (기존 유지): 회사소개, 홍보센터, 고객지원(A/S문의·오시는길·SNS)
├─ [신규] 업종별 솔루션 메뉴 추가
│   ├─ 일반 쇼케이스 랜딩 (소매 상공인 대상)
│   │   ├─ 히어로: 신뢰 문구 + 즉시 상담 CTA
│   │   ├─ 업종별 진입: 식당 / 정육점 / 카페 등
│   │   ├─ 설치 사례 확장 (기존 "매장의 품격" 섹션을 업종별 필터링 가능하도록 확장)
│   │   ├─ 고객 후기 (동종업계 사장님)
│   │   ├─ 가격/AS 안내
│   │   └─ 상담 신청 폼
│   └─ 특수 쇼케이스 랜딩 (의료기관·참치 전문점 대상)
│       ├─ 히어로: 전문성/인증 강조
│       ├─ 업종별 진입: 의료기관 / 수산물·참치 전문점 등
│       ├─ 인증서·스펙 자료 (위생, 정밀온도) — 현재 없음, 신규 제작 필요
│       ├─ 납품/설치 사례
│       └─ 전문 상담 폼
└─ 기존 제품소개(제품 유형별 카탈로그) 메뉴는 유지 — 기존 대형 B2B 고객 및 상세 스펙 검토용
```

기존 대형 B2B 고객을 위한 제품 유형별 카탈로그는 유지하되, 메인 진입은 신규 업종별 랜딩이 우선되도록 메인 페이지 상단 구성을 조정한다.

## 7. 페이지별 요구사항

### 7.1 공통 영역
- 헤더 메뉴: `업종별 솔루션(일반/특수) | 시공사례 | 회사소개 | 상담문의`
- 신뢰 배지 바: 설립연도, 인증/특허, 주요 납품실적(숫자 강조)
- 푸터: 사업자정보, 연락처, 서비스이용약관, 개인정보처리방침 (기존 유지)

### 7.2 일반 냉장고 랜딩 (세그먼트 A)
- 히어로: 광고 유입 시 3초 내 핵심 메시지 노출, 톤은 구체적/실용적
- 업종별 카드: 식당 / 정육점 / 카페 등 진입점 (제품 스펙명이 아닌 업종명으로 분류)
- Before/After 시공 사진, 사장님 후기(가능하면 영상/사진 포함)
- 가격대/AS 정책 안내 (정가 미노출 시 "상담 후 견적" 명시)
- 상담 폼 필드(제안): 업종, 매장 규모, 희망 설치일, 연락처

### 7.3 특수 냉장고 랜딩 (세그먼트 B/C)
- 히어로: 전문성/신뢰 강조 (인증마크, 조달 이력 등)
- 업종별 진입: 의료기관 / 수산물·참치 전문점
- 인증서/스펙 자료 다운로드 또는 열람 (PDF)
- 납품 사례(가능한 경우 기관명 비식별 처리 또는 동의받은 사례만 노출)
- 전문 상담 폼 필드(제안): 기관/업체 유형, 필요 용량, 설치 환경, 규정 준수 요구사항

## 10. 기술 스택 제안

현재 사이트 URL이 `index.asp` 형태인 것으로 보아 **Classic ASP 또는 ASP.NET 기반**으로 운영 중일 가능성이 높다(그누보드는 PHP 기반이므로 해당하지 않음). 정확한 기반 기술은 담당 개발사/호스팅사 확인이 필요하다. 개편 방향은 두 가지 옵션이 있다.

### 옵션 A. 기존 ASP 기반 유지 + 신규 섹션/페이지 추가
- 장점: 기존 디자인 자산(다크톤 아이덴티티, 설치사례 UI 등) 재사용 가능, 마이그레이션 리스크 적음
- 단점: ASP 계열은 최신 프론트엔드 프레임워크 대비 유지보수 인력 확보가 어려울 수 있고, 신규 업종별 랜딩처럼 인터랙션이 많은 페이지 구현에 제약이 있을 수 있음
- 권장 상황: 기존 개발사와 지속 계약 중이거나, 예산/일정이 촉박한 경우

### 옵션 B. 신규 스택 구축 (권장)
- **프론트엔드**: Next.js (SSR/SSG로 SEO 대응) + Tailwind CSS
- **CMS**: 헤드리스 CMS(예: 콘텐츠팀이 시공사례/후기를 직접 등록할 수 있어야 하므로) 도입 검토
- **백엔드/폼 처리**: 상담 폼 제출 → API → DB(또는 Google Sheet/CRM 연동), 이메일 알림
- **분석**: GA4 + 광고 매체 전환 스크립트(네이버/메타 픽셀 등)
- **호스팅**: Vercel 등 서버리스 환경 또는 기존 서버 유지
- **결제 확장 대비**: Phase 2에서 결제 모듈(PG사 연동)을 붙이기 쉽도록 상품/문의 데이터 모델을 처음부터 "주문 가능한 구조"로 설계해 두는 것을 권장 (예: 문의 폼 자체를 향후 "장바구니 담기 전 단계"로 확장 가능하게 설계)

> 최종 스택 선택은 예산, 운영 인력의 기술 역량, 그누보드 자산(회원, 게시글 등) 이관 필요 여부에 따라 결정 필요.

## 11. 콘텐츠/데이터 요구사항 (운영팀 준비 필요)

- **업종별로 재분류할 시공/납품 사례**: 기존에 이미 40건+ 설치사례가 있으므로 신규 촬영보다는 **업종 태그를 붙여 재구성**하는 작업이 우선 (예: 편의점/마트 사례 → "식당·정육점" 랜딩으로, 베이커리/아이스크림 사례는 그대로 노출)
- **구매결정 FAQ 신규 작성**: 기존 FAQ(성에 제거, 소음 등 A/S성 질문)와 별도로, "가격대는?", "설치 가능 지역은?", "설치까지 얼마나 걸리나요?" 등 소상공인이 구매 전 궁금해할 질문 신규 작성 필요
- **동종업계 후기**: 기존 설치사례 사진에 사장님 인터뷰/후기 텍스트를 추가하는 방식으로 확장 (전면 신규 촬영보다 효율적)
- **인증서 재구성**: ISO 9001/14001, Inno-Biz, Main-Biz 등 기존 인증은 이미 확보되어 있으므로, 다운로드 가능한 스캔본 PDF화 및 배지 형태로 재활용
- 특수 쇼케이스(의료기관·참치전문점)용 추가 인증/스펙이 필요한지 확인 (기존 인증은 일반 품질/기업 인증이며, 의료기기 규격 등 업종 특화 인증은 별도 확인 필요)
- 업종별(식당/정육점/카페/의료기관/참치전문점) 소개 문구 및 대표 이미지
- 가격 정책 방향 (정가 노출 여부, 상담 후 견적 방식 여부)
